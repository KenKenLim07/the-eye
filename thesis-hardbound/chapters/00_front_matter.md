# List of Notations

This section lists key acronyms, metrics, and symbols used throughout the manuscript.

| Notation / Acronym | Meaning |
|---|---|
| IPO | Input–Process–Output conceptual framework. |
| NLP | Natural Language Processing. |
| NER | Named Entity Recognition. |
| PH | Philippines / Philippine context. |
| VADER | Valence Aware Dictionary and sEntiment Reasoner (lexicon/rule‑based sentiment). |
| DistilBERT (SST‑2) | A lightweight transformer sentiment model fine‑tuned on the SST‑2 dataset (binary polarity). |
| Hybrid sentiment engine | Routing‑based approach combining VADER(+PH patch) and DistilBERT depending on language signal. |
| $r$ | Pearson correlation coefficient (used for comparing daily average sentiment time series across sources). |
| Accuracy | Proportion of correct predictions in an evaluation set. |
| F1, Macro‑F1 | Classification performance metrics; Macro‑F1 averages per‑class F1 equally. |
